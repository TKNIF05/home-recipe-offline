# 家常 · 本地菜谱 PWA
本仓库公开的 site.zip 只包含程序、通用测试菜谱、示例 PDF 和离线阅读器资源。私人菜谱、PDF、备注及备份保存在使用者自己的设备中，不由应用上传。
## 使用
GitHub Pages 发布完成后，用浏览器打开站点，在 Android Chrome 或 iPhone Safari 中添加到主屏幕。等待“离线资源及 PDF 阅读器已就绪 · 网络版 v5”再断网验证。无需安装证书或运行电脑服务。
## 发布方式
GitHub 的标准 Ubuntu 托管执行器解压 site.zip 并部署静态资源；不使用付费执行器、付费套餐或自定义域名。部署动作固定至官方提交版本，构建凭据不留在检出目录，部署产物只保留一天。
修改程序时先在本地测试，再更新完整 site.zip。包内含全部应用源码和依赖许可证，不需要在线构建、CDN 或 npm 安装。
## 测试范围
单条菜谱、材料和调料、PDF 离线显示、备注编辑、本地保存、JSON 备份恢复。v5 增加旧单条记录到集合存储的兼容迁移，保留原菜谱 ID 和 PDF；界面仍为单条菜谱。尚未实现多菜谱管理或双向合并同步。
新网址是独立数据空间：从旧版导出 JSON，再在新站点导入。浏览器存储并非永久备份，请保留外部 JSON。新版本下载后，先保存修改并关闭全部旧窗口，再重新打开。
## v5 升级验收
升级前另存 JSON 备份；联网打开应用并等待更新提示，保存修改后关闭全部菜谱窗口，再从原主屏幕图标打开。应显示“阶段 2 · 兼容验证 v5”及离线资源就绪；核对原备注和 PDF，再测试断网重开、编辑保留及 JSON 导出恢复。iPhone 可从系统分享菜单选择保存到“文件”。无需卸载或清理网站数据。
Windows 隔离浏览器已验证 v4 → v5 升级和离线阅读；v5 手机真机回归待反馈。
## 安全边界
不含分析统计、广告、外部在线脚本或账号系统。托管平台可能记录常规访问日志。应用代码能读取自己的本地数据，发布账号及未来更新应受到保护；建议启用 GitHub 双重验证。不要上传私人数据、备份或密钥。
